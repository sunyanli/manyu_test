# 需求理解与细化（G1）：日常待办事项 H5

> 任务来源：帮助用户记录日常待办事项；核心功能＝新增待办事项；事项字段＝名称 + 描述 + 截止时间；目标用户＝内部用户；最小闭环＝仅创建。
> 本文档为 G1 需求细化产物，是 G2 设计选型的输入。首轮澄清已完成，结论已回填「澄清问答记录」，无未决问题。

---

## 形态结论

- **形态**：支付宝开放平台「网页 & 移动应用」下的**第三方纯 H5**（React + TS + AntD Mobile + Next，SSR/SSG），**不是支付宝小程序**，不使用 `my.*`、`AlipayJSBridge` 容器 JSAPI、离线包。
- **受众与收录（已确认）**：纯内部工具，**不需要公网收录/SEO/分享落地**。全站页面以 **B 类（noindex、登录后使用）** 处理，`robots.txt` 全站 noindex、不产出 sitemap；不设 A 类公开页。
- **最小闭环（已确认）**：严格按「仅创建」收敛。本期 **Must** =「新建待办（名称 + 描述 + 截止时间）+ 待办列表可见 + 创建成功反馈 + 空状态引导」；完成/编辑/删除/详情/搜索等列入 Should/Could，作为后续迭代。
- **使用场景（已确认）**：仅在支付宝 App 内打开；不做浏览器降级引导页，也不需要外部分享落地。
- **能力边界（已确认）**：登录走支付宝 OAuth（`publicAppAuthorize` 服务端跳转换 uid，可选 `ap.getAuthCode` 半屏）；**支付不做**；**字段含截止时间**（选填，日期时间选择器）；**多语言中英双语**（i18n）。

- 留存/转化：依赖空状态/引导与零门槛；不做强运营。

### MoSCoW 分级（推荐本期范围）

- **Must（本期最小闭环「仅创建」）**：F1 新增待办（名称/描述/截止时间）、F2 列表页、F3 成功反馈、F4 空状态/引导、F11a 截止时间、F20 多语言（中英 i18n）。
  - 原则：能建、能看见、有反馈、空态不空；字段含截止时间；界面中英双语。
- **Should（紧随其后的下一迭代，低成本的完整 CRUD）**：F5 详情、F6 完成、F7 删除、F8 编辑、F9 登录（数据隔离）。

> 说明：任务「最小闭环＝仅创建」与「原则上不少于 5 页」的通用发散要求存在张力。我以**用户明确的最小闭环为 Must**，完整 CRUD（可自然形成 ≥5 页）列为 Should 并在 Q4 询问是否本期扩围；不擅自把空壳页凑数。

## 接口清单

> 开发期优先 mock（MSW 拦截 fetch 或 Next route handler 兜底），与真实后端同签名；SSR 期 mock 不得抛错致整页降级。

| 方法 | 路径 | 用途 | 入参 | 返回 | 鉴权 | 本期 |
|---|---|---|---|---|---|---|
| POST | `/api/todos` | 新建待办 | `{name, description?, dueAt?}` | `{id, name, description, dueAt, status, createdAt}` | 登录态（uid） | Must |
| GET | `/api/todos` | 待办列表 | `?cursor=&limit=20` | `{items[], nextCursor}` | 登录态 | Must |
| GET | `/api/todos/:id` | 详情 | — | 单条完整字段 | 登录态 | Should |
| PATCH | `/api/todos/:id` | 编辑/完成 | `{name?, description?, dueAt?, status?}` | 更新后对象 | 登录态 | Should |
| DELETE | `/api/todos/:id` | 删除 | — | `{ok}` | 登录态 | Should |
| POST | `/api/auth/code` | auth_code 换 uid（服务端） | `{authCode}` | `{uid, token}` | 服务端签名 | Should |

## 非功能要求

- **多语言（已确认：中英双语）**：本期纳入 i18n 基建（Next.js App Router + 语言包，URL/query 参数或 Cookie 持久化语言偏好），首屏中英文案需覆盖；代码/接口/标识符不变，文案走统一 i18n key。
- **无障碍（a11y）**：语义化标签、图片 `alt`、表单 `label`/`aria-label`、`:focus-visible`、触控目标 ≥44px、颜色对比 WCAG AA、不纯靠颜色传状态。
- **性能预算**：首屏 LCP < 2.5s（P75）、CLS < 0.1、INP < 200ms；移动端优先；SSR/SSG + CDN + 图片优化（本期 B 类页以 CSR 为主，预算按骨架屏 + 接口缓存控制）。JS bundle 预算 ≤ 200KB（gzip 后，首个交互页面）。
- **环境与降级**：`isAlipayClient()` 判定；B 类页浏览器打开给"请在支付宝中打开"+ alipays scheme 唤起；公开页不挡浏览器（如改 A 类）。
- **安全**：服务端密钥（AppId/私钥）只读服务端 env，绝不入前端 bundle；登录态数据服务端按 uid 隔离。
- **上线与灰度（默认假设）**：本期先交付可运行 demo，无正式灰度要求；正式上线时走 CDN 权重 + feature flag + Sentry/RUM 监控（见 Q10）。
