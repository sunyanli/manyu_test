# 待办事项创建功能实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有 FastAPI 服务中新增 `POST /api/todos` 接口，使内部用户能够创建带有名称和描述的待办事项。

**Architecture:** 复用现有 SQLite 数据库存储，新增 `todos` 表；通过 Pydantic 模型解析请求体，在路由层完成业务校验，沿用统一错误响应格式返回结果。

**Tech Stack:** FastAPI 0.104.1, Pydantic, SQLite, pytest, httpx

---

## Global Constraints

- FastAPI 0.104.1
- Pydantic 请求校验
- SQLite 本地存储
- 沿用现有错误响应格式 `{success, data}` / `{success, error_code, message, detail}`
- 仅实现创建，不实现查询/修改/删除/状态/权限

- [ ] **Step 6: 实现 `POST /api/todos` 接口**

  在 `app.py` 的核心接口区域添加：

  ```python
  @app.post("/api/todos", status_code=201)
  async def create_todo(request: Request, body: CreateTodoRequest):
      if not body.name or len(body.name) > 100:
          raise HTTPException(
              status_code=400,
              detail={
                  "success": False,
                  "error_code": "ERR_TODO_001",
                  "message": "待办名称不能为空或超过 100 字符",
                  "detail": None,
              },
          )
      if body.description is not None and len(body.description) > 500:
          raise HTTPException(
              status_code=400,
              detail={
                  "success": False,
                  "error_code": "ERR_TODO_002",
                  "message": "待办描述不能超过 500 字符",
                  "detail": None,
              },
          )
      try:
          todo_id = str(uuid.uuid4())
          ts = datetime.now(timezone.utc).isoformat().replace("+00:00", "Z")
          with sqlite3.connect(DB_PATH) as conn:
              conn.execute(
                  "INSERT INTO todos (id, name, description, created_at) VALUES (?, ?, ?, ?)",
                  (todo_id, body.name, body.description, ts),
              )
              conn.commit()
          return {
              "success": True,
              "data": {
                  "id": todo_id,
                  "name": body.name,
                  "description": body.description,
                  "created_at": ts,
              },
          }
      except Exception:
          raise HTTPException(
              status_code=500,
              detail={
                  "success": False,
                  "error_code": "ERR_TODO_003",
                  "message": "待办创建失败，请稍后重试",
                  "detail": None,
              },
          )
  ```

## 验收标准

- `POST /api/todos` 接受 `name`（必填，≤100 字符）与 `description`（可选，≤500 字符）。
- 成功时返回 201 与 `{success: true, data: {id, name, description, created_at}}`。
- 名称非法时返回 400，`error_code` 为 `ERR_TODO_001`。
- 描述超长时返回 400，`error_code` 为 `ERR_TODO_002`。
- 所有新增测试通过。
